# Promotion Shadow existing-item artwork

These bitmap files are copies of artwork already present in the base Client
for item IDs 24000-24005. They are mapped onto the existing Promotion Shadow
gacha IDs 24012-24017 without changing item IDs, names, properties, or rates.

Mapping:

- 24012 Weapon uses 24001 Weapon artwork
- 24013 Armor uses 24000 Armor artwork
- 24014 Shoes uses 24003 Shoes artwork
- 24015 Shield uses 24002 Shield artwork
- 24016 Earring uses 24004 Earring artwork
- 24017 Pendant uses 24005 Pendant artwork
