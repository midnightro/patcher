# MIDNIGHT RO — Client Patch Repository

Patch assets for the MIDNIGHT RO launcher (`MidnightRO.exe`, built on
[rpatchur](https://github.com/L1nkZ/rpatchur)).

Everything the launcher downloads lives in the **`patches` release** of this repo:

- `plist.txt` — the patch list, one `<index> <file>.thor` per line
- `NNNN_YYYYMMDD_<name>.thor` — the patch archives themselves
- `patch_status.js` — latest index/file consumed by the Launcher UI

## Rules

- The `patches` tag is permanent. Never delete or move it — the launcher's
  `patch_url` points straight at it.
- Patch indexes only ever go up. Never edit or replace a `.thor` that has already
  been published; ship a new, higher-numbered patch instead. The launcher records
  the last applied index on each player's machine.
- Patches contain loose files only (`use_grf_merging: false`). The game client uses
  GRF version 0x300, which rpatchur cannot merge safely.

## news.js

The `patches` release also carries `news.js`, which is **not** a patch. The
launcher loads it as a script every time it opens and shows it in the news panel,
so news can change without shipping anyone a new `launcher_ui/` (that folder is
excluded from every patch - the webview holds it open, see BUG-069).

- source of truth: `tools/patcher/news.js` in this repository
- publish: `gh release upload patches tools/patcher/news.js --repo midnightro/patcher --clobber`
- unlike a `.thor`, this file **is** meant to be overwritten in place

If it is missing, malformed, or the player is offline, the launcher falls back to
the news bundled in their `launcher_ui/config.js` and says nothing - so check it
parses before uploading.

Patches are generated by `tools/patcher/make_patch.ps1` in this repository.

## patch_status.js

`make_patch.ps1` regenerates and uploads this ES5 file for every published
patch. The Launcher UI loads it with a timestamp query and displays the current
`N/N` count and latest THOR filename. Never hand-edit the count in `index.html`.
Upload order is THOR → `patch_status.js` → `plist.txt`, so a status-upload
failure cannot publish a new patch index to players.
